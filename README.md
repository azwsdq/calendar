## О проекте

**Calendar Bot** — это асинхронный Telegram бот, разработанный на Python с использованием фреймворка aiogram. Приложение позволяет пользователям управлять своим личным календарем прямо в Telegram:

- ✅ Создавать события с названием, описанием, датой и временем
- ✅ Просматривать все созданные события
- ✅ Редактировать существующие события
- ✅ Удалять события из календаря
- ✅ Получать справку по использованию бота

Все данные безопасно хранятся в локальной SQLite базе данных.

## Установка

### Шаг 1: Клонирование репозитория

```bash
git clone https://gitflic.mtuci.ru/project/troparevskii-stoparik/kanban-calendar.git
cd kanban-calendar
```

### Шаг 2: Создание виртуального окружения

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### Шаг 3: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 4: Конфигурация

1. Получите токен у **@BotFather** в Telegram
2. Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=ваш_токен_здесь
ADMIN_ID=ваш_id_пользователя
```

Или установите переменную окружения:
```bash
export BOT_TOKEN="ваш_токен"
```

### Шаг 5: Запуск бота

```bash
python bot.py
```

Вы должны увидеть сообщение о запуске бота:
```
Бот успешно запущен...
```

## Использование

### Основные команды

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота и приветственное сообщение |
| `/add` | Добавить новое событие |
| `/events` | Просмотреть все события |
| `/help` | Справка по использованию |
| `/calendar` | Открыть календарь (временно отключено) |

### Примеры использования

#### Создание события

1. Отправьте команду `/add` или нажмите кнопку **➕ Создать событие**
2. Введите название события: `Встреча с клиентом`
3. Введите описание (или `/skip` для пропуска): `Обсуждение нового проекта`
4. Укажите дату в формате **ДД-ММ-ГГГГ**: `15-03-2026`
5. Укажите время (или `/skip` для пропуска): `14:30`

#### Просмотр событий

Нажмите кнопку **📋 Все события** для просмотра полного списка

#### Редактирование события

1. Найдите нужное событие в списке
2. Нажмите на него для просмотра
3. Нажмите **✏️ Редактировать**
4. Внесите необходимые изменения

## Структура проекта

```
calendar/
├── bot.py                 # Основной файл с обработчиками
├── database.py            # Работа с SQLite базой данных
├── keyboards.py           # Клавиатуры и кнопки
├── config.py              # Конфигурация и переменные
├── requirements.txt       # Зависимости проекта
├── calendar.db            # База данных (создается автоматически)
└── README.md              # Этот файл
```

### Описание файлов

**bot.py** — главный модуль приложения
- Инициализация бота и диспетчера
- Регистрация обработчиков команд
- Логика конечного автомата (FSM)
- Обработка callback запросов

**database.py** — работа с базой данных
- Инициализация таблиц
- Функции CRUD операций
- Асинхронные запросы к БД

**keyboards.py** — интерфейс пользователя
- Создание инлайн клавиатур
- Кнопки для навигации
- Кнопки для действий

**config.py** — конфигурация приекта
- Загрузка переменных окружения
- Параметры приложения

## Формат данных

### Дата

**Формат:** ДД-ММ-ГГГГ

Примеры:
- `01-01-2026` — 1 января 2026
- `25-12-2026` — 25 декабря 2026
- `31-03-2026` — 31 марта 2026

### Время

**Формат:** ЧЧ:МИ

Примеры:
- `09:00` — 9 утра
- `14:30` — 2:30 дня
- `23:59` — 11:59 вечера

## Troubleshooting

### Проблема: "Ошибка подключения к Telegram"

**Решение:**
- Проверьте интернет-соединение
- Убедитесь, что токен вводится правильно
- Переопубликуйте токен у @BotFather

### Проблема: "Ошибка при чтении базы данных"

**Решение:**
- Удалите файл `calendar.db`
- Перезапустите бота
- База будет пересоздана автоматически

### Проблема: "Команда не работает"

**Решение:**
- Убедитесь, что бот имеет необходимые права
- Проверьте логи на наличие ошибок
- Перезагрузите чат команду `/start`

### Проблема: "SyntaxError при запуске"

**Решение:**
- Проверьте версию Python (требуется 3.8+)
- Установите зависимости заново: `pip install -r requirements.txt`
