# todo-calendar (site)

***
## Что оно должно делать?
Это сайт который, на данный момент времени, при заходе на него, показывает календарь с текущим месяцем. В будущем планируется добавить возможность создавать события и напоминания, а также синхронизировать их с другими календарями.
Также планируется добавить возможность создавать несколько календарей, например, для работы, для личных дел и т.д.

Еще планируется синхронизация с Телеграмом (если его не заблокируют конечно)

## Технологии
 - FastAPI
 - Jinja2
 - SQLAlchemy
